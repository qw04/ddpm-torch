# Mitigating Iterative Retraining Effects in Synthetic Datasets

This project investigates the degradation and distributional drift that occurs when machine learning models are iteratively retrained on 
synthetic data generated by previous models. The goal is to evaluate and mitigate these effects through controlled retraining pipelines, 
dataset curation strategies, and model size comparisons.

## Experiment Overview

Each experiment follows a modular pipeline:

1. Generate or load synthetic datasets
2. Iteratively retrain models on synthetic data
3. Apply mitigation strategies (curation, accumulation, model scaling)
4. Evaluate performance and distributional changes
5. Visualise results via plots and generated images

## Assumptions & Configuration

- Python ≥ 3.x
- Required dependencies are listed in `requirements.txt`
- Dataset paths and output directories are defined within individual scripts
- Experiments may be computationally expensive depending on model size


## Outputs

Depending on the experiment, scripts may produce:
- Saved plots (`.png`, `.pdf`)
- Generated image samples
- Logged metrics across retraining iterations

Outputs are written to experiment-specific directories.


## Motivation

As synthetic data becomes increasingly common, models are often trained on data generated by previous models. Understanding and 
mitigating the long-term effects of this feedback loop is critical for reliable deployment of generative systems.
